# 🧑‍💻 Team App

> 👥 원격 팀을 위한 협업 플랫폼  
> 원격 팀을 위한 협업 환경을 컨셉으로 하여, 서비스의 일부 기능인 메인 페이지, 블로그, 회원가입 및 로그인 인터페이스를 구현한 프로젝트입니다.

전체 플랫폼의 모든 기능을 완성하기보다, HTML 구조의 시맨틱한 설계와 웹 표준 준수라는 기본기에 집중하여 개발했습니다. 화려한 시각적 효과보다는 ARIA 속성 적용, 키보드 네비게이션 최적화 등 '누구나 제약 없이 접근 가능한 웹'을 만드는 과정을 연습하는 데 목적을 두었습니다. Lighthouse 및 W3C 검사 도구를 활용해 접근성 경고를 최소화하며 견고한 마크업 구조를 구축했습니다.
